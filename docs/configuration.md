# Configuration

CogZ is configured via `.cogz/config.toml`, generated by `cogz init`. The file is typed, validated at startup, and version-controlled with your project.

## Full default config

```toml
[project]
name = "my-project"

[storage]
db_path = ".cogz/cogz.db"

[embedding]
code_model = "nomic-ai/CodeRankEmbed-int8"
knowledge_model = "BAAI/bge-base-en-v1.5"
dimension = 768
nli_model = "cross-encoder/nli-deberta-v3-xsmall"
auto_download = true
model_idle_ttl = 300
model_min_free_mb = 512

[search]
fts_weight = 0.3
vec_weight = 0.4
code_vec_weight = 0.3
rrf_k = 60
max_results = 20
min_source_proportion = 0.2
source_balance_enabled = false

[consolidation]
dedup_threshold = 0.85
title_match_threshold = 0.85
contradiction_check = true
promotion_threshold = 3
contradiction_threshold = 0.7
contradiction_cosine_threshold = 0.85
contradiction_length_ratio = 5.0
dedup_nli_threshold = 0.85

[index]
allow = []
deny = []

[retention]
observation_prune_after_days = 90
tombstone_max_count = 1000

[context]
default_token_budget = 4096
task_token_budget = 8192
escalation_token_budget = 8192
cold_start_rules = 5
task_max_results = 25
task_max_hops = 2
escalation_max_results = 20
escalation_max_hops = 3
```

## Section reference

### `[project]`

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | string | autodetected | Project identifier. Autodetected from git remote or directory name on init. Metadata only — not a query filter. |

### `[storage]`

| Field | Type | Default | Description |
|---|---|---|---|
| `db_path` | string | `.cogz/cogz.db` | SQLite database path, relative to repo root. Must be beneath `.cogz/`. |

### `[embedding]`

| Field | Type | Default | Description |
|---|---|---|---|
| `code_model` | string | `nomic-ai/CodeRankEmbed-int8` | Model ID for code entity embeddings. Must match `dimension`. |
| `knowledge_model` | string | `BAAI/bge-base-en-v1.5` | Model ID for knowledge entity embeddings. Must match `dimension`. |
| `dimension` | usize | `768` | Embedding dimension. Must match both models' registry dimensions. |
| `nli_model` | string | `cross-encoder/nli-deberta-v3-xsmall` | NLI model for contradiction detection and merge confirmation. |
| `auto_download` | bool | `true` | Download models from HuggingFace on first use. Set `false` for FTS-only or air-gapped setups. |
| `model_idle_ttl` | u64 | `300` | Seconds before idle ONNX models unload from memory. `0` = never unload. |
| `model_min_free_mb` | u64 | `512` | Minimum free RAM (MB) to load a model. Below this, degrades to FTS-only. `0` = no check. |

**Available models** (see `src/embed/registry.rs`):

| Model ID | Size | Dim | Use |
|---|---|---|---|
| `nomic-ai/CodeRankEmbed-int8` | 139 MB | 768 | Code embeddings (default, INT8 quantized) |
| `nomic-ai/CodeRankEmbed` | 548 MB | 768 | Code embeddings (full precision) |
| `BAAI/bge-base-en-v1.5` | 210 MB | 768 | Knowledge embeddings (default) |
| `BAAI/bge-small-en-v1.5` | 64 MB | 384 | Knowledge embeddings (lighter, lower quality) |
| `cross-encoder/nli-deberta-v3-xsmall` | 87 MB | — | NLI contradiction detection (default, quantized) |

If you change `dimension`, you must also change both `code_model` and `knowledge_model` to models with matching dimensions. Config validation cross-references the registry and rejects mismatches at startup.

### `[search]`

| Field | Type | Default | Description |
|---|---|---|---|
| `fts_weight` | f64 | `0.3` | Weight for FTS5 results in RRF fusion. |
| `vec_weight` | f64 | `0.4` | Weight for knowledge vector results in RRF fusion. |
| `code_vec_weight` | f64 | `0.3` | Weight for code vector results in RRF fusion. |
| `rrf_k` | u32 | `60` | RRF smoothing constant. Lower = sharper ranking. Must be > 0. |
| `max_results` | u32 | `20` | Max results before graph expansion. Must be > 0. |
| `min_source_proportion` | f64 | `0.2` | Floor for each source type's proportion in balanced fusion. Ensures neither code nor knowledge is completely suppressed. |
| `source_balance_enabled` | bool | `false` | Enable query-sensitive source balancing. Experimental — the fixed 0.5/0.5 split outperforms balance detection on overall retrieval quality. |

### `[consolidation]`

| Field | Type | Default | Description |
|---|---|---|---|
| `dedup_threshold` | f64 | `0.85` | Minimum cosine similarity to flag a duplicate. Range 0.0–1.0. |
| `title_match_threshold` | f64 | `0.85` | Levenshtein-based fuzzy title match threshold. Range 0.0–1.0. |
| `contradiction_check` | bool | `true` | Enable NLI-based contradiction detection on insert. |
| `promotion_threshold` | u32 | `3` | Minimum supporting observations to promote an observation to a rule. |
| `contradiction_threshold` | f64 | `0.7` | Minimum P(contradiction) to flag a pair. Calibrated against XNLI. |
| `contradiction_cosine_threshold` | f64 | `0.85` | Minimum embedding similarity for a contradiction pair. Genuine contradictions share the same topic. |
| `contradiction_length_ratio` | f64 | `5.0` | Maximum text length ratio for a contradiction pair. Texts differing more are likely different content types. |
| `dedup_nli_threshold` | f64 | `0.85` | Minimum bidirectional P(entailment) to confirm a duplicate merge. Both directions must exceed this. |

### `[index]`

| Field | Type | Default | Description |
|---|---|---|---|
| `allow` | array of strings | `[]` | Glob patterns for files to index despite being gitignored. Patterns are relative to repo root (`*`, `**`, `?`, `[abc]`). |
| `deny` | array of strings | `[]` | Glob patterns for files to exclude from indexing even if not gitignored. Use cases: vendored code, generated files. Allow takes precedence over deny. |

### `[retention]`

| Field | Type | Default | Description |
|---|---|---|---|
| `observation_prune_after_days` | u32 | `90` | Age threshold for pruning eligibility. Only `rejected` and `superseded` observations older than this are prunable. Must be > 0. |
| `tombstone_max_count` | u32 | `1000` | Maximum number of pruned tombstones to retain. |

### `[context]`

| Field | Type | Default | Description |
|---|---|---|---|
| `default_token_budget` | usize | `4096` | Token budget for cold_start context packs. Must be > 0. |
| `task_token_budget` | usize | `8192` | Token budget for task context packs. Must be > 0. |
| `escalation_token_budget` | usize | `8192` | Token budget for escalation context packs. Must be > 0. |
| `cold_start_rules` | usize | `5` | Number of recent rules to include in cold_start mode. |
| `task_max_results` | u32 | `25` | Max search results in task mode before expansion. |
| `task_max_hops` | usize | `2` | Graph expansion hops in task mode. |
| `escalation_max_results` | u32 | `20` | Max search results in escalation mode before expansion. |
| `escalation_max_hops` | usize | `3` | Graph expansion hops in escalation mode. |

## Validation

Config is validated at startup. The following are checked:

- `project.name` is not empty
- `storage.db_path` is relative, beneath `.cogz/`, and contains no `..`
- `embedding.dimension` matches both models' registry dimensions
- `search.rrf_k` and `search.max_results` are > 0
- `consolidation.dedup_threshold` and `title_match_threshold` are in [0.0, 1.0]
- `retention.observation_prune_after_days` is > 0
- All token budgets are > 0

Invalid config exits with an error message before any DB or file operations occur.
