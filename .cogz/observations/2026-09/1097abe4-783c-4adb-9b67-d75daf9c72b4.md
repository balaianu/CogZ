The MCP API in params.rs does not expose a supporting_ids parameter for record_observation. This means the promotion lifecycle (observation to rule) cannot be triggered through MCP alone — users must manually edit observation files to add supporting_ids frontmatter. The file sync in refs.rs correctly handles supporting_ids when present, but the API gap prevents normal usage.
