The default Aho-Corasick MatchKind is LeftmostFirst, which returns the match with the lowest pattern index at the same starting position. This causes shorter name patterns to shadow longer path patterns. LeftmostLongest picks the longest match at the leftmost position, which is correct for path-based auto-linking.
