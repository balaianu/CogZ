The ort library (ONNX Runtime) emits duplicate schema registration warnings to stderr during model loading. Messages like 'Schema error: Trying to register schema with name Abs (domain:  version: 1) from file ./onnx/defs/math/old.cc line 2747, but it is already registered'. This is ort's internal behavior, not a CogZ bug. It's noisy in test output but harmless — the schemas are registered correctly despite the warning. The warnings appear during both cargo test and cogz index/reindex when ONNX models are loaded.
