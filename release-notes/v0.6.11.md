## CogZ v0.6.11

Maintenance patch — second November dependabot batch, applied on top
of the v0.6.10 ISA fix.

### Highlights

- **`rusqlite` 0.41 → 0.43** — bundled SQLite 3.54.1 plus several
  use-after-free fixes (ChangesetIter, column_metadata,
  Filter::in_values). Note: rusqlite now rejects empty/comment-only
  SQL strings — CogZ never issues empty statements.
- **`rmcp` =3.11.0** — stays on the exact-pin policy; MCP client and
  server APIs unchanged for our usage.
- **Patch bumps** — `clap` 4.6.8, `uuid` 1.29.3, `regex` 1.13.2,
  `filetime` 0.2.30.
- **Base image digests** — `rust` and `debian` Dockerfiles refreshed.
- **`ossf/scorecard-action` 2.6.0**.

### Upgrade notes

No functional or API changes — dependency-only patch. Binaries ship
with the baseline-x86 fix from v0.6.10, so linux x86_64 remains
portable to pre-AVX2 CPUs.
