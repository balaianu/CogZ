## CogZ v0.6.7

Patch release fixing hook output contracts across supported agents,
plus a routine dependency batch.

### Highlights

- **`hookEventName` now echoes what actually fired.** Agents that send
  `hook_event_name` on stdin (Devin, Gemini, Codex) get that name back
  in `hookSpecificOutput`. Previously CogZ tagged output with its
  internal lifecycle name — `PostCompaction` firings emitted
  `"SessionStart"`, and Gemini's `BeforeAgent`/`AfterTool`/`AfterAgent`
  emitted `UserPromptSubmit`/`PostToolUse`/`Stop`, all invalid under
  strict per-event output schemas.
- **New `--record-only` flag for `capture-event`.** Runs the full
  lifecycle (event record, reindex triggers) but emits nothing.
  `cogz configure` now wires it for compact events that cannot inject
  context — Claude/Codex `PostCompact`, Cursor `preCompact`, Gemini
  `PreCompress` — where a populated `hookSpecificOutput` would fail
  validation or be ignored.
- **Devin project hooks file fixed.** `.devin/hooks.v1.json` is now
  written as the bare hooks object, as Devin's docs require — `cogz
  configure` previously nested it under a `"hooks"` key. Devin's
  `PostCompaction` keeps its context injection (the stdin echo tags it
  correctly); other agents' compact hooks now record silently.
- **Dependencies refreshed.** 8 dependabot PRs: `rmcp` 3.5.1 → 3.7.0
  (MCP SDK), plus `ureq`, `tokio`, `toml_edit`, `serde_json`, `uuid`,
  `schemars`, `sha2`, `zerocopy`, `libc`; CodeQL 4.39.0, scorecard
  2.5.0, rust-toolchain pin, and Docker base digests. `libz-sys` moved
  to 1.1.31 for RUSTSEC-2026-0418 (env leak in build script).
- **Smaller docker build context.** `.dockerignore` now excludes
  `fuzz/target`, `fuzz/corpus`, and `fuzz/artifacts` — local
  `docker build` no longer ships multi-GB fuzz artifacts.

### Upgrade notes

Re-run `cogz configure` to pick up the corrected hook wiring — most
importantly `cogz configure devin`, which rewrites `hooks.v1.json` in
the correct bare shape (previously generated project configs are not
read by Devin). Compact-event hooks gain `--record-only`; nothing else
changes shape. No data migration needed.
