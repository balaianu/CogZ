## CogZ v0.6.9

Maintenance patch — a dependency batch that clears all five RUSTSEC
advisories flagged by `cargo audit`, plus CI hygiene fixes.

### Highlights

- **SQLite CVE fixed.** `rusqlite` 0.40 → 0.41 pulls a patched
  `libsqlite3-sys` (RUSTSEC-2026-0459).
- **`rmcp` 3.7 → 3.10** — fixes unbounded response-body buffering in
  Streamable HTTP clients (RUSTSEC-2026-0462).
- **Transitives updated** — `url` 2.5.9 (nested-`blob:` stack
  overflow), `libz-sys` 1.1.33 (heap buffer overflow), `quinn-udp`
  0.5.16 (receive-loop spin).
- **`cargo audit` is green again** — the daily scheduled CI failure
  since Nov 16 is resolved.
- **Workflow hygiene** — `github/codeql-action` steps are now grouped
  in Dependabot config; split version bumps broke CodeQL analyze at
  runtime. Digest bumps for `rust`, `debian`, `rustls` (fuzz), and
  `action-gh-release` 3.0.4 included.

### Upgrade notes

No functional or API changes — dependency-only patch. Upgrade is
recommended for the SQLite and rmcp security fixes.
