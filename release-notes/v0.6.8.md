## CogZ v0.6.8

Infrastructure patch completing the v0.6.7 release — identical code,
now with the full platform asset set.

### Highlights

- **macOS build restored.** v0.6.7's macOS job was blocked by the
  scheduled `macos-14` runner brownout (retires 2026-11-02). The CI
  and release matrices migrated to `macos-15`; `aarch64-apple-darwin`
  builds, checksums manifest, and registry publish now complete.

### Upgrade notes

No functional change versus v0.6.7 — see `release-notes/v0.6.7.md` for
the hook output-contract fixes (`hook_event_name` echo, `--record-only`
compact events, bare `.devin/hooks.v1.json`) and the dependency batch.
Upgrade to v0.6.8 for the signed macOS binary; the v0.6.7 release
remains usable everywhere else.
